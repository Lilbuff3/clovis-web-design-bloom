# Clovis Web Design

Hand-grown websites for Fresno & the Central Valley by Adam Youssef. Live at
[cloviswebdesign.com](https://cloviswebdesign.com).

React 19 + TypeScript, Vite 7, Tailwind CSS v4. Deployed on Vercel: a push to `main`
goes to production.

```bash
npm install
npm run dev
npm run build
```

See [AGENTS.md](AGENTS.md) for the project layout, deploy details and rules.
